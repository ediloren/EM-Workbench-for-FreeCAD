Creating FasterCap and FastCap models

The FC tools convert FreeCAD geometry into a panel model for capacitance extraction. The usual workflow is: configure the solver, assign geometry to conductors and dielectric interfaces, create and inspect the panelization, then export the solver files.

1. Prepare the CAD model

  • Use one consistent geometric scale and choose the same scale in the FCSolver Units property.
  • Decide which small gaps, coatings, holes and contacts are physically intentional. They can substantially affect capacitance.
  • Prefer valid, clean FreeCAD solids or faces. Models imported from STEP may need repair if they contain invalid faces, duplicated surfaces or very small edges.
  • You do not normally need to cut a conductor out of a surrounding dielectric. The panelization can classify a solid conductor embedded in a dielectric region.

2. Configure FCSolver

An FCSolver is created automatically with the first FC object if the document does not already contain one. You can also create it with FasterCap / FastCap Solver. Use one FCSolver per document.

PropertyUser choice
DimensionSelect 3D for ordinary surface-panel models or 2D for a FasterCap cross-section model. See the dedicated 2D section below.
TargetSolverSelect FasterCap or FastCap. Two-dimensional models require FasterCap.
UnitsSelect the unit represented by the FreeCAD coordinates. Exported coordinates are converted accordingly.
SpacePermittivityRelative permittivity of the background material surrounding regions for which no more specific dielectric applies.
GeometryToleranceNumerical tolerance used to compare and classify geometry. Keep the default unless the CAD model has a known numerical-scale problem. This setting is not a gap-closing or defeaturing control.
ReferenceConductorRequired in 2D. Select the FCConductor that represents the zero-potential reference.
MaxPanelSizeMaximum panel edge length for FastCap. It does not control FasterCap panel size.
Folder / FilenameDestination folder and list filename. The .lst extension is added when needed.

The remaining FasterCap and FastCap properties correspond to command-line solver controls. Change them only when you want to alter the solver's refinement, accuracy or iteration behavior; they do not change the CAD geometry.

3. Define conductors

  1. Select a solid, shell, surface or one or more faces and click FCConductor.
  2. Use a separate FCConductor for every independent electrical potential. Disconnected pieces may belong to one FCConductor when they are intentionally at the same potential.
  3. To add geometry to an existing conductor, select that FCConductor together with the additional geometry and click FCConductor again.
  4. Set DefaultPermittivity to the relative permittivity immediately outside conductor portions not covered by a more specific dielectric region.

Different FCConductors must not occupy the same physical volume or share a surface. If two metal parts make electrical contact, assign them to the same FCConductor. If they represent different potentials, provide the intended physical separation.

4. Define dielectric regions and interfaces

  1. Select a dielectric solid or the faces describing a dielectric boundary and click FCDielectric.
  2. Set InnerPermittivity and OuterPermittivity.
  3. Select the FCDielectric and inspect its arrows. The arrow points toward the Outer side; the opposite side is Inner. For a solid, the enclosed material is normally on the Inner side. For an open interface, set Orientation to Reversed if the arrows point the wrong way.
  4. To add geometry to an existing dielectric, select the FCDielectric together with the additional geometry and click FCDielectric again.

A conductor may be partly or completely embedded in a dielectric solid. A solid conductor may also touch a dielectric boundary. Do not define the same dielectric interface more than once, and avoid partially overlapping dielectric volumes with incompatible permittivities.

Open faces describe only the selected interfaces; they do not define the material throughout an enclosed volume. Use them when the interface and its two material sides are known explicitly.

5. Two-dimensional FasterCap models

A 2D model represents a cross-section that is assumed to extend uniformly perpendicular to the drawing plane. It is useful for transmission-line and other long, constant-cross-section structures.

  1. Set FCSolver Dimension to 2D and TargetSolver to FasterCap. FastCap export does not support the FasterCap 2D segment format.
  2. Create the cross-section in the global X/Y plane. Use planar faces whose boundary edges describe the conductor and dielectric contours. All meaningful contours should use the same Z level because Z is omitted from the exported 2D coordinates.
  3. Do not use the side faces of extruded solids as the 2D model. Edges that change in Z are rejected, and geometry on different Z planes would project onto the same X/Y model.
  4. Create one FCConductor for each electrical potential and assign the contour face or faces to it.
  5. Create FCDielectric objects for material boundaries and verify Inner/Outer orientation with the arrows. The face normal and boundary direction determine the side of each exported segment, so reversing an incorrectly oriented interface is important.
  6. Set FCSolver ReferenceConductor to the conductor that represents zero potential. A valid reference conductor is mandatory for 2D panelization.
  7. Create the panelization and inspect the segment contours. Correct open contours, unintended duplicate edges, crossings and collapsed segments before export.

PanelCurvatureTolerance controls how finely curved contour edges are divided. Smaller values preserve curves more closely but create more segments. Straight edges normally remain single segments. The 3D FastCap MaxPanelSize control is not a FasterCap 2D discretization control.

6. Optional defeaturing

Defeaturing is off by default. When enabled, it creates an approximate analysis geometry while leaving the original FreeCAD Base geometry unchanged. Use it only when the permitted geometric change is acceptable for the required capacitance accuracy.

  1. Enable DefeaturingEnabled on FCSolver to apply the solver defaults.
  2. DefeaturingRelativeSize selects features and near-contact situations small enough to consider. The value is relative to the size of the individual source component, not the complete document.
  3. DefeaturingRelativeDeviation limits the accepted movement or shape change relative to that component size. A value of zero prevents geometry changes.
  4. Choose Align contacts when small contact mismatches may be aligned. Choose Align and regularize when a slight change to curved geometry is also acceptable to remove difficult tangent or near-tangent contacts.
  5. For each FC object, Defeaturing: Inherit uses the solver settings, Disabled protects that object's geometry, and Custom enables its own controls.
  6. DefeaturingPriority helps choose which participant remains fixed during contact alignment. Higher-priority and Disabled objects are preferred as references.

Defeaturing is intended for small, ordinary CAD imperfections. It may not resolve complex imported surfaces, arbitrary splines, non-convex contacts or severely invalid geometry. Review every defeaturing warning and compare the panelized result with the original model. Disable it or reduce the limits when a small gap, coating or feature is physically important.

7. Control discretization

Each FCConductor and FCDielectric has a PanelCurvatureTolerance. Smaller values follow curved geometry more closely and generally create more panels; larger values give a coarser representation. A coarse mesh can be useful for FasterCap, but it must still represent the geometry well enough for the required accuracy.

For FastCap 3D models, FCSolver MaxPanelSize additionally limits panel edge length. Very small features, narrow gaps, sharp corners and tangent contacts can force a dense mesh regardless of the chosen curvature tolerance.

8. Create and inspect the panelization

  1. Click Create FC Panelization. A progress dialog shows the current phase and provides a Cancel button. Cancellation may wait briefly for the current geometry or meshing operation to finish.
  2. After successful panelization, the source objects are hidden and the FC objects display the frozen panels or 2D segments. You can show a source object again to compare it with the analysis model.
  3. Read the Report view. Correct errors and review warnings, especially those concerning contacts, overlaps, gaps, orientation, defeaturing and problematic panels.
  4. Inspect material boundaries, seams and curved areas visually. Red panels identify individual panels for which a problem was detected.
  5. Panelize again after changing geometry, Base assignments, material values, discretization or defeaturing settings. The displayed panelization does not update automatically.

The panelization is transient. The CAD model and its settings are saved in the FreeCAD document, but the panels must be recreated after reopening it.

9. Export

  1. Set the destination Folder and Filename on FCSolver.
  2. Click Export FasterCap / FastCap. The folder receives the list file and its referenced geometry files.
  3. If files already exist, confirm whether they may be overwritten.
  4. If the panelization contains errors, the workbench warns that the exported model may be incomplete or invalid and asks whether to continue. Exporting does not make those errors harmless.

Export writes the last panelization that you inspected. If the CAD model or FC properties changed afterward, the workbench warns that the snapshot is stale. Panelize again when the changes must be included.

10. Troubleshooting checklist

  • Missing panels: check Base assignments, source visibility, invalid faces and Report view diagnostics.
  • Wrong dielectric side: select the FCDielectric, inspect its arrows and change Orientation if necessary.
  • Unexpected conductor permittivity: verify dielectric volumes and the conductor's DefaultPermittivity.
  • Too many panels: use a larger PanelCurvatureTolerance, simplify genuinely irrelevant small features, or enable carefully bounded defeaturing.
  • Bad triangles or failed curved contacts: repair the source CAD, remove exact tangencies when physically permissible, or use a controlled defeaturing setting.
  • 2D validation errors: verify that every contour lies in the X/Y plane, no edge changes in Z, and the ReferenceConductor is set.
