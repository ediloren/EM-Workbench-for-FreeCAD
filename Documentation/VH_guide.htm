Creating VoxHenry models

The VH tools convert FreeCAD solid geometry into a uniform voxel model for VoxHenry resistance and inductance extraction. The usual workflow is: configure the solver, assign conductor materials, define positive and negative port contacts, voxelize and inspect the model, then export the solver input file. Commands are available in the E.M. VoxHenry tools toolbar and the EM menu.

1. Prepare the CAD model

  • Use valid, closed 3D solids based on objects derived from Part::Feature. Repair null or invalid imported shapes before creating VHConductors. Open faces, wires and sketches alone do not define conductor volumes.
  • Choose one consistent geometric scale. VHSolver units specifies the physical length represented by one numerical CAD coordinate unit; check it explicitly before export.
  • Model the intended current paths, return paths, gaps, holes and conductor thicknesses. The voxel model must preserve their connectivity and separation.
  • Avoid overlapping conductor volumes and duplicate assignments of the same solid. Each voxel stores only one conductor index; later voxelization can overwrite an earlier conductor's assignment without reporting a material conflict.
  • Provide accessible surface faces for both contacts of each port. Keep the original solids available for face selection even when the VH objects hide them.

This workflow has no FC-style dielectric objects, surface panelization, 2D cross-section mode or defeaturing controls. Geometry is sampled on a common three-dimensional grid. Empty grid cells are not dielectric regions with user-assigned permittivity.

2. Configure VHSolver

Create a VHSolver, or let the first VHConductor create one automatically. Use one VHSolver per document. The export routine uses the first solver it finds if there are several. Keep the normally created solver object: the VHVoxelizeAll command looks for the document object with internal name VHSolver.

PropertyUser choice
deltaSide length of every cubic voxel, in numerical CAD coordinate units. Must be positive. The default is 1.0. Smaller values resolve finer geometry and increase memory use and computation time.
unitsPhysical scale of the CAD coordinates and delta. Choices are km, m, cm, mm, um, nm, in and mils; the default is um. Export converts delta to metres.
fmin / fmaxFrequency range in Hz used to generate the frequency list. Defaults are 2.5e9 and 1.0e10. Use a positive range with fmax at least fmin; for the normal list-generation path, fmin must be greater than 1e-6 Hz.
ndecDesired number of logarithmic frequency steps per decade. Use a positive value; the default is 1. Check the resulting freq list, especially for a range shorter than a decade.
freqActual frequencies exported, in Hz. This editable list is regenerated whenever fmin, fmax or ndec changes. Set a custom list after those properties if explicit frequency points are required.
Folder / FilenameDestination folder and input filename. Defaults are the user's home folder and voxhenry_input_file.vhr. Include the desired extension yourself; export does not append it automatically.
VoxelSpaceX / VoxelSpaceY / VoxelSpaceZRead-only grid dimensions calculated from the bounding box of all VHConductor Base objects and delta.
VoxelSpaceDimRead-only product of the displayed grid dimensions. This includes empty space and is not the number of occupied conductor voxels or a complete memory estimate.
voxelSpaceValidRead-only grid-validity flag. It does not certify that all conductors and ports have been voxelized or that the model is physically correct.

For a model drawn at ordinary FreeCAD millimetre scale, choose mm. For example, a CAD length of 10 with units = mm represents 10 mm, while the same coordinates with units = um represent 10 micrometres. Changing units changes the exported physical scale; it does not resize the CAD geometry or change which cells are occupied. With delta = 1 and units = mm, the exported voxel size is dx=0.001 metres.

The generated frequencies start at fmin and advance by a factor of 10^(1/ndec). The list stops at the last such point within the range; fmax is not necessarily included. The default range and ndec produce only the 2.5e9 Hz point. Inspect freq before export rather than assuming that both endpoints will be simulated.

3. Define conductors and materials

  1. Select the original solid object and click VHConductor. Selecting several eligible objects creates a separate VHConductor for each.
  2. Check Base, the link to the original object. Each VHConductor has one Base link. Selecting a subface does not restrict the conductor to that face: the command uses the selected object's whole shape.
  3. Set Sigma to the material conductivity in S/m. The default is 5.8e7 S/m. This value is exported directly and is independent of the solver's length units.
  4. Leave Lambda at zero for an ordinary conductor. For a superconducting material, set its London penetration depth as described below.
  5. Use a separate VHConductor for each material assignment. For several solids in one Base, prepare an appropriate solid compound or union in the CAD model first.

CondIndex is an automatically assigned, read-only identifier used to mark material ownership in the grid. It is not a fixed-potential assignment. Disconnected pieces do not become electrically connected merely because they belong to the same VHConductor. Likewise, different VHConductor objects do not insulate adjacent occupied voxels. Inspect the voxel geometry wherever contact or isolation matters.

The Base object is hidden on creation. Before voxel display is enabled, the VHConductor normally shows its bounding box, not the original solid. Show Base again when you need to inspect curved geometry or select actual terminal faces.

4. Define ports

A VHPort contains two groups of surface contacts: PosFaces for the positive terminal and NegFaces for the negative terminal. Both groups must produce voxel contacts. Contacts can be on the same solid or on different solids according to the intended electrical model.

  1. Show the original conductor solids and hide obstructing bounding boxes or voxel previews.
  2. Select two actual CAD faces, one for each terminal, then click VHPort.
  3. Inspect PosFaces and NegFaces. The command collects the selected faces in the order supplied by FreeCAD, assigns the first half to PosFaces and the remainder to NegFaces. With two faces, the first is positive and the second negative. For an odd number of faces, the negative group receives the extra face.
  4. Edit those face lists when a terminal needs multiple faces or when the selection produced the wrong grouping. Recheck references after CAD edits that change face numbering.
  5. Give every port a distinct, simple Label, preferably without whitespace. The exporter writes the label directly as the port name.

The default positive-contact color is red and the negative-contact color is black. The View properties PosPortColor and NegPortColor control these colors. Check the face lists as well as the display, particularly when several faces belong to one object.

A port maps selected CAD faces onto nearby surface faces of occupied voxels. It does not create conductor volume. Voxelize the conductors before their ports. Use exposed terminal surfaces; a buried interface between occupied cells is not an ordinary external port surface.

5. Control voxel resolution and port matching

delta controls the entire model; there is no per-conductor voxel size or local refinement setting. The grid is aligned with the global X, Y and Z axes and starts at the minimum corner of the combined conductor bounding box. Moving or adding geometry can change this origin and therefore the sampling of other conductors.

Conductor occupancy is based on sampling the solid at voxel centres. Curved and inclined surfaces become stair steps. Features smaller than delta can disappear, and narrow gaps or contacts can change topology. Start with a manageable grid, inspect the result, then reduce delta until the geometry and extracted quantities are sufficiently stable. A successful voxelization flag alone does not show that a thin conductor retained any occupied cells.

The grid spans empty space between conductors as well as metal. Halving delta increases the number of grid cells by roughly eight for a fixed bounding box. Temporary geometry-processing arrays, the preview and the external solver require additional memory. Widely separated solids can therefore be expensive even when their metal volume is small.

Each VHPort has DeltaDist, the matching distance as a percentage of delta. Its default is 55. Candidate voxel-face centres are accepted when their distance to a selected CAD face is less than delta * DeltaDist / 100. This is a geometric proximity test, not an exact face-area projection or a restriction to the selected solid's conductor index.

If terminal cells are missing, first check the conductor voxelization and the selected faces. Adjust DeltaDist carefully if the stair-step surface is too far from the CAD face. A larger value can collect side faces or nearby unintended conductors; a smaller value can omit the intended contacts. Inspect both terminals after every adjustment and ensure their contact sets do not overlap.

6. Create and inspect the voxelization

  1. Click VHVoxelizeAll to voxelize all VHConductors, followed by all VHPorts, in the document.
  2. For a limited update, select the relevant VHConductors and VHPorts and click VHCondPortVoxelize. This command processes selected conductors before selected ports. A grid change affects the complete model, so use VHVoxelizeAll after changing delta or the overall geometry.
  3. Read the Report view and check isVoxelized on every conductor and port. A port requires nonempty contacts on both sides; a completion message can still follow a warning about missing contacts.
  4. Set ShowVoxels to true on the objects you want to inspect. Voxelization resets this property to false; creating the voxel data does not automatically display it.
  5. Hide the original solids as needed to see the voxel surfaces. Check thin sections, gaps, holes, conductor junctions and both terminals of every port. Show the Base geometry again to compare it with the approximation.

ShowVoxels changes the display only. The conductor preview shows the outer voxel shell, not each interior cell. Toggling the preview or recomputing the document is not a substitute for voxelizing again.

Changing delta invalidates the voxel grid and object voxelizations. Changes to a port's PosFaces, NegFaces or DeltaDist invalidate that port. Other geometry edits are not comprehensively tracked: a changed shape with the same bounding box can leave old voxel data marked valid. Explicitly revoxelize after modifying Base geometry or assignments, and revoxelize ports after changing the conductors they contact.

After deleting conductors or making extensive structural edits, rebuild the grid to remove possible old occupied cells. From the FreeCAD Python console, with the intended document active, use from freecad.EM import EM; EM.getVHSolver().Proxy.getVoxelSpace(force=True), then run VHVoxelizeAll and inspect again.

7. Superconducting conductors

Set a positive Lambda on each superconducting VHConductor. Lambda is a FreeCAD length quantity: enter an explicit physical unit, for example 50 nm. Unlike the numerical CAD scale controlled by VHSolver units, Lambda is converted from its own quantity to metres during export.

If any VHConductor has Lambda greater than zero, the exporter adds the Superconductor declaration and writes a Lambda column for every exported conductor voxel. Ordinary conductors in the same model retain Lambda = 0. Sigma is still written. Check both material quantities against the intended material model; setting Lambda does not automatically choose a conductivity.

8. Save and update the model

The implementation saves the solver's occupied voxel data and bounding box, the port contact lists and preview data with the FreeCAD document. Voxelization is therefore intended to persist across saving and reopening. After reopening, check the validity flags, references and previews; revoxelize if anything is invalid or the geometry has changed.

Frequency settings, units, Sigma and Lambda are read at export time. Changes to those values do not require different occupied cells, but they do require a new export. Changes to geometry, delta or terminal matching require voxelization and inspection before exporting again. Keep the saved CAD document and exported input file together so that the material settings and geometry used for a run can be identified.

9. Export and run VoxHenry

  1. Complete voxelization and inspection. Confirm that every intended conductor and port is present and valid, and check the actual freq list and physical units.
  2. Set VHSolver Folder and Filename, for example model.vhr. Prefer an existing writable folder. The exporter can create a single missing directory but does not recursively create missing parent directories.
  3. Click VHInputFile. Its tooltip may refer to FastHenry, but this command writes the VoxHenry input file.
  4. If the file already exists, confirm whether it may be overwritten.
  5. Read the Report view for skipped objects and other warnings. Inspect the generated file before using it in an external VoxHenry run.

The output is one text file containing freq=, voxel size dx= in metres, grid dimensions LMN=, a voxel list with conductivity values, and port contact records. Superconducting models include the additional declaration and Lambda values. Voxel indices in the file are one-based; port records use P/N terminal identifiers and signed coordinate directions for voxel faces.

Export does not run voxelization or provide a comprehensive stale-model validation. Objects marked unvoxelized are skipped with Report view warnings, and a file can still be written with missing conductors or ports. A grid change discovered during export can also invalidate data. A “Finished exporting” message is not a guarantee of a complete or valid model. Correct the cause, voxelize all objects again and repeat the export.

VHInputFile prepares the input only. Run VoxHenry separately using the procedure for your solver installation. These VH commands do not launch the solver or import its results into FreeCAD. Compare results from progressively finer voxel grids when assessing discretization accuracy.

10. Troubleshooting checklist

  • Only boxes are visible: show Base to see the CAD solids, or voxelize and enable ShowVoxels to see the sampled conductor surfaces.
  • Missing or broken conductor: check Base, solid validity, delta and the grid alignment. Thin regions may contain no voxel centres. Inspect overlaps that may have overwritten another material.
  • Unexpected connection or isolation: inspect occupied cells at gaps and junctions. Refine delta or correct the CAD; conductor names and indices do not impose electrical separation or connections.
  • Port has no voxel contacts: voxelize conductors first, check both face lists, confirm the faces lie within the global conductor bounding box, and inspect DeltaDist.
  • Port contacts extend onto unwanted surfaces: check nearby metal, terminal grouping and DeltaDist. Reduce the matching distance or refine the grid, then inspect both polarities again.
  • Wrong physical size or material scale: check units and the exported dx. Sigma is in S/m; Lambda is an explicitly dimensioned length exported in metres.
  • Missing frequency endpoint: inspect freq. Increase ndec or enter an explicit list after setting fmin and fmax.
  • Excessive memory use: increase delta for an initial inspection or reduce unnecessary extent of the model. Empty space inside the overall bounding box contributes to grid allocation.
  • Old geometry remains after edits: force a grid rebuild as described above, run VHVoxelizeAll, and regenerate the previews and input file.
  • Incomplete export: check every isVoxelized flag and the Report view. Resolve warnings before relying on the output file.
